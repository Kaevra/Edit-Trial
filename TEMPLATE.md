# Template Glimpse.inc
- Cover: 3 warna (orange = saham berat, hijau = saham tidak terlalu berat, pink = saham ringan). Dipilih per materi.
- Slide isi: selalu gradien "body" (template ke-4).
- Posisi gradien diacak per slide (tombol "Acak gradien" di mode Edit). Warna tetap.
- Logo dan footer: public/template/logo.png dan footer.png (dipotong dari template).
- Tombol "Visit Us" dibuat dengan kode (lib/template.js > button) dan hanya muncul di cover.
- Font: taruh di public/fonts, isi lib/template.js > fonts, lalu fontHead / fontBody.
- Ukuran huruf isi 34, penekanan 50: lib/template.js > size.
